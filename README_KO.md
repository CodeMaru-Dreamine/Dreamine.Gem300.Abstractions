# Dreamine.Gem300.Abstractions

확인된 GEM300 도메인 경계를 위한 공급자 중립 계약, 불변 모델 및 상태 Enum입니다.

[➡️ English Version](https://github.com/CodeMaru-Dreamine/Dreamine.Gem300.Abstractions/blob/main/README.md)

Object Services, Carrier Management, Substrate Tracking, Process Job,
Control Job 및 프로세스 내 Domain Event Journal을 분리합니다.
`Dreamine.Gem.Abstractions`와 `Dreamine.Secs.Abstractions`만 참조합니다.

구체 GEM/GEM300 구현이나 통신 공급자를 참조하지 않습니다. 계약 자체는 표준 wire
mapping 또는 현재 Revision 적합성을 의미하지 않습니다. E116/E116.1 Normative
원문을 확보하기 전까지 Equipment Performance 계약은 의도적으로 제공하지 않습니다.
